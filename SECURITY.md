# Security

Voice Studio is a single-user tool that listens on `127.0.0.1` only. Its defences and the tests that cover them are listed in [README.md](README.md#security) and [docs/TESTING.md](docs/TESTING.md).

To report a vulnerability, use GitHub's private vulnerability reporting on this repository (Security tab → Report a vulnerability) with steps to reproduce. Please do not open a public issue.
